# 서귀포시 불법주정차 단속구간

업로드된 지도 이미지를 Leaflet의 이미지 지도 방식으로 표시하는 조회용 웹앱입니다.

## 포함 기능

- 서귀포시 대륜동 부근 단속구간 이미지 표시
- 확대, 축소, 드래그 이동
- 전체 보기 버튼
- 범례 표시
- CCTV 임시 마커 14개 표시
- CCTV 목록 클릭 시 해당 위치로 이동
- 단속 시간 안내
- 좌표 확인 모드
- 향후 빨간색 단속구간 지도 추가를 위한 레이어 구조

## 단속 시간

- 파란색 도로: 평일 07:30 ~ 19:00
- 빨간색 도로: 평일 07:30 ~ 21:00, 향후 추가 예정
- 파란색·빨간색 공통: 주말·공휴일 09:00 ~ 18:00

## 로컬 실행 방법

Node.js를 설치한 뒤 아래 명령어를 실행합니다.

```bash
npm install
npm run dev
```

브라우저에서 터미널에 표시되는 주소를 엽니다. 보통 아래 주소입니다.

```text
http://localhost:5173
```

## CCTV 이름과 위치 수정

`public/data/cctv.json` 파일을 수정하면 됩니다.

```json
{
  "id": "cctv-01",
  "name": "CCTV1",
  "x": 452,
  "y": 148,
  "memo": "고정식 불법주정차 단속 CCTV. 위치명은 향후 수정 예정입니다."
}
```

- `name`: 화면에 표시할 이름입니다.
- `x`, `y`: 이미지 안의 좌표입니다.
- `memo`: 팝업에 표시할 설명입니다.

## 좌표 확인 방법

1. 앱 상단의 `좌표 확인 모드`를 켭니다.
2. 지도에서 원하는 위치를 클릭합니다.
3. 왼쪽 패널의 `좌표 확인` 영역에 `{ "x": ..., "y": ... }`가 표시됩니다.
4. 해당 값을 `cctv.json`에 복사해서 사용합니다.

## 빨간색 단속구간 지도 추가 방법

1. 빨간색 단속구간이 표시된 이미지를 `public/maps/red-map.jpg`로 추가합니다.
2. `public/data/mapLayers.json`에서 빨간색 레이어를 아래처럼 수정합니다.

```json
{
  "id": "red",
  "name": "빨간색 단속구간",
  "imageUrl": "/maps/red-map.jpg",
  "available": true,
  "weekdayTime": "평일 07:30 ~ 21:00",
  "weekendHolidayTime": "주말·공휴일 09:00 ~ 18:00",
  "description": "빨간색 도로가 단속구간입니다."
}
```

단, 빨간색 지도 이미지도 현재 이미지와 같은 크기인 1254 × 704 px이면 가장 편합니다. 크기가 다르면 `src/App.jsx`의 `IMAGE_SIZE` 값을 새 이미지 크기에 맞춰 조정해야 합니다.

## 무료 배포 추천

처음에는 GitHub 사용 연습을 겸해 GitHub Pages 또는 Vercel을 추천합니다.

### Vercel 추천 이유

- GitHub 저장소와 연결하면 자동 배포됩니다.
- React/Vite 프로젝트 배포가 쉽습니다.
- 무료 플랜으로 시작할 수 있습니다.

### GitHub Pages 추천 이유

- GitHub만으로 정적 웹사이트를 무료 호스팅할 수 있습니다.
- 다만 Vite 프로젝트에서는 `base` 설정이 추가로 필요할 수 있습니다.

처음 배포는 Vercel이 더 쉽고, GitHub는 코드 보관 및 협업용으로 같이 사용하는 것을 추천합니다.
